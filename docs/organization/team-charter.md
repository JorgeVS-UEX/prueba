# Team charter y organización

## Contexto de la empresa desarrolladora

NightShift Software es el equipo de desarrollo del proyecto académico. Su propósito es diseñar, implementar y validar una plataforma web demostrable para venta simulada de entradas, listas de RRPP y control de aforo. El cliente de referencia es Grupo Velvet Nights S.L.; el entorno y todos los datos son ficticios o sintéticos. El proyecto no procesa pagos reales ni se conecta a sistemas comerciales.

## Acuerdos de trabajo

- Iteraciones de una semana según la constitución, con fechas confirmadas al planificar.
- Toda funcionalidad debe mantener trazabilidad desde el objetivo y la historia hasta código, pruebas y evidencia.
- Las decisiones de alcance, prioridad, estimación, tarifas y compromiso corresponden al equipo/PO y deben quedar registradas.
- El uso de IA es asistencial: revisar evidencia y propuestas antes de incorporarlas; registrar entrada, propuesta, justificación, decisión, modelo y herramienta disponibles.
- El equipo revisará este charter cuando cambien integrantes, roles o responsabilidades.

**Pendiente de validación:** ratificación del equipo, fecha y canal oficial de comunicación/decisiones.
