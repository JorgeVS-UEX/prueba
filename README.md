# proyecto-gps-26-27-gc01

Proyecto académico de NightShift Software para diseñar y construir una plataforma web demostrable de venta simulada de entradas, atribución de RRPP y control de aforo para Grupo Velvet Nights S.L. Solo se usarán datos sintéticos; no se integran pagos reales.
 
## Equipo y organización

El equipo y los roles declarados se documentan en [docs/organization/team-charter.md](docs/organization/team-charter.md). La capacidad de Sprint 1 está registrada en [docs/organization/capacity.md](docs/organization/capacity.md); los datos no confirmados están marcados como pendientes.

## Estructura

- `.specify/memory/constitution.md`: principios y gobernanza del proyecto.
- `specs/product/`: misión y objetivos/alcance.
- `specs/EP-00X-*/spec.md`: épicas e historias de usuario.
- `specs/definition-of-ready.md` y `specs/definition-of-done.md`: criterios compartidos de calidad.
- `docs/organization/`: constitución del equipo, decisiones y capacidad.
- `.github/agents/`: revisores de requisitos y planificación.

## Wiki y decisiones

La [Wiki del repositorio](https://github.com/UniExtremadura/proyecto-gps-26-27-gc01/wiki) es el destino previsto para las decisiones del equipo. El [registro local de decisiones](docs/organization/decisions.md) y el [log de trazabilidad de IA](docs/project/ai-traceability.md) sirven de respaldo documental; no implican que exista o se haya sincronizado contenido en la Wiki.

## Instalación y ejecución

Instrucciones por completar tras acordar el entorno y el comando de ejecución del incremento. Las versiones iniciales deben ser reproducibles:

1. Instalar las herramientas y dependencias indicadas por los manifiestos del proyecto.
2. Configurar únicamente datos y credenciales sintéticos/de prueba.
3. Ejecutar el comando de inicio y las pruebas definidos para el incremento.

**Pendiente:** el repositorio consultado no contiene aún manifiesto de aplicación, comando de arranque ni pasos técnicos específicos. Actualizar esta sección cuando el incremento ejecutable y su entorno estén disponibles; no inventar comandos.
